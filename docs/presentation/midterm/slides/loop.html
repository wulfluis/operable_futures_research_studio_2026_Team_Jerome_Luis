SECOND LOOK · FRAME 09 / 12

(40 s) The engineer is not a backup; they are part of the system. It always starts with a resident: a photo and a few survey answers. Computer vision draws the crack: a U-Net in PyTorch, trained on CrackSeg9k. The rules read it through the risk matrix: crack pattern times width gives the category. An engineer confirms or corrects every Category 3 and every referral. Those corrections retrain the model, and the loop comes back to computer vision, a little better each time. A new model only replaces the old one if, on the same test, it misses no more cracks and raises fewer false alarms: that is how v3 replaced v1.
