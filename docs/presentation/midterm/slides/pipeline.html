SECOND LOOK · FRAME 06 / 12

(50 s) Under the hood it is a computer vision pipeline in six steps. One: a quality gate checks sharpness with two blur measures; a bad photo gets Retake. Two: a U-Net with a ResNet-34 encoder segments every crack pixel. Three and four, next: width in millimetres from a printed scale card, and the context: the crack pattern and which element it sits on, from our survey. Five: written, auditable rules from a risk matrix give the level and the reason. Six: an engineer confirms every Category 3 and every referral. Only one of these is a trained AI model: the U-Net in step two, built in PyTorch and fine-tuned on CrackSeg9k. Context will add more models later. Everything else is a written rule, and no language model runs inside Second Look. One AI model draws the crack; rules decide; a human confirms.
